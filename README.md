# Sprite Cutter

<img src="https://www.256arts.com/spritecutter/icon_scutter.png" alt="Sprite Cutter icon" width="128" align="right">

Cut a sprite sheet into individual sprite images, right on your device.

Drop in or import a spritesheet, set the sprite size (or how many rows and columns you want), adjust spacing, and export every sprite as a separate PNG.

[Download on the App Store](https://apps.apple.com/app/sprite-cutter/id1562779425) · [256arts.com/spritecutter](https://www.256arts.com/spritecutter/)

<img src="https://www.256arts.com/spritecutter/shot1.webp" alt="A loaded spritesheet with sprite size and spacing controls, ready to cut" width="300">

## Features

- **Drag and drop or import** — bring in a spritesheet from Finder, Files, or another app, or use File > Import Spritesheet… on Mac.
- **Cut by size or by count** — set the sprite width and height, or the number of columns and rows, and the other side updates automatically.
- **Spacing support** — account for gaps between sprites in the sheet before cutting.
- **Export as individual PNGs** — each sprite saves out as its own file, named Sprite 1, Sprite 2, and so on.
- **Shortcuts and Siri** — cut a spritesheet from the Shortcuts app or by voice, no need to open the app.
- iPhone, iPad, Mac, and Apple Vision Pro.

## Building

Open `Sprite Cutter.xcodeproj` in the latest Xcode and run the `Sprite Cutter` scheme. See [`AGENTS.md`](AGENTS.md) for the architecture.
